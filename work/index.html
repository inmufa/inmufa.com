SYNAPSSE

Creator · open source, MIT

A local-first memory graph for AI agents. An async Python daemon over embedded SQLite exposes itself through the Model Context Protocol and renders the resulting graph as an interactive WebGL canvas. Retrieval is hybrid — FTS5 keyword search alongside vector similarity from ONNX embeddings running locally — so recall costs a fraction of replaying a transcript, and nothing leaves the machine.

Founder · sole engineer

A small IT agency I started, built end to end: a Next.js landing with a lead form, a FastAPI service that saves each lead before notifying admins and retries failed Telegram sends on its own, and an aiogram support bot so clients can leave a request by chat instead of a form.
